## Project Overview

This project uses real-world data to predict whether an individual is a victim of identity theft. I apply two different classification approaches — a **decision tree** and **logistic regression** — and evaluate their performance using standard metrics such as confusion matrices, ROC curves, AUC, and lift.

The goal of the project is not just prediction accuracy, but also understanding **which factors matter most** and how different modeling techniques compare in practice.

---

## Data

The project uses two datasets stored in the `data/` folder:

- **Stolenrecords2.csv**  
  Contains individual-level information related to identity theft incidents and demographic characteristics.

- **Crimebystate.csv**  
  Contains state-level crime statistics (e.g., murder, robbery, assault, burglary).

The crime dataset is cleaned and merged with the identity theft data to enrich the feature set.

> **Note:** The datasets are not generated by the code. They must be downloaded and placed in the `data/` folder for the notebook to run.

---

## Data Preparation

Before modeling, the following steps are performed:

- Dropping irrelevant or redundant columns (e.g., location fields, account existence flags).  
- Handling missing values by imputing column means.  
- One-hot encoding categorical variables (such as employment type).  
- Splitting the data into training and testing sets (70% / 30%).  
- Ensuring no data leakage by using training-set statistics for test-set imputation.

---

## Models Used

### Decision Tree Classifier
- Max depth limited to avoid overfitting.  
- Tree structure is printed and visualized.  
- Model performance evaluated using:
  - Confusion matrix
  - Misclassification rate
  - ROC curve and AUC
  - Lift at 10% and 20%

### Logistic Regression
- Used for comparison and interpretability.  
- Coefficients analyzed to identify the most influential variables.  
- Evaluated using confusion matrix and misclassification rate.
